# Nova City 2088: A Sustainable Future

A self-contained, single-file futuristic eco-city website. The complete application is in `index.html` (HTML, CSS, and JavaScript together). It uses browser Canvas 2D, SVG, CSS animations, and optional Web Audio; no build step or server-side code is required.

## Run locally

Open `index.html` in a modern browser. For the best experience, use a current version of Chrome, Edge, Firefox, or Safari. Sound starts only after you turn it on using the header toggle.

## Deploy with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` to the repository root (the same level as this README; do not put it inside another folder).
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose your main branch and the `/(root)` folder, then click **Save**.
6. Wait for GitHub Pages to publish and open the URL shown in Settings → Pages.

## Resident access demo and privacy

The citizen portal is a fictional demonstration. It uses a normal multi-step profile form and a short city-network processing animation; it does not request facial images, fingerprints, or any biometric verification. The pass image is generated locally in the browser. The form does not submit to a server or issue a real government credential.

City telemetry, transport figures, energy values, and personal wellness values are illustrative simulations, not live city data or medical measurements.
