# Neo-Veridia: Vision of 2088

A self-contained, single-file futuristic eco-metropolis website. The complete application is in `index.html` (HTML, CSS, and JavaScript together). It uses browser Canvas and optional Web Audio; no build step or server-side code is required.

## Run locally

Open `index.html` in a modern browser. For the best experience, use a current version of Chrome, Edge, Firefox, or Safari. Sound starts only after you turn it on using the header toggle.

## Deploy with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` to the repository root (the same level as this README; do not put it inside another folder).
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose your main branch and the `/(root)` folder, then click **Save**.
6. Wait for GitHub Pages to publish and open the URL shown in Settings → Pages.

The website is a fictional interactive demo. The citizen portal keeps its sample form data in the current browser session and generates the pass image locally; it does not submit a real visa or residency application.
